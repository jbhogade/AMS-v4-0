Replace Mobile

Replacing . Pick an In-Store (unassigned) mobile to take over this mobile's current assignment. The old mobile is marked "Replaced" and both records stay cross-linked in their Mobile ID Record. If no suitable In-Store mobile exists, use + to add a new mobile first, then select it here.

Only In-Store (unassigned) mobiles of the selected type are listed. The + button opens the Add Mobile form.
Defaults to today - when the replacement was handed over.
Accessories handed over with the replacement. Pre-filled from the selected replacement mobile, or from the old mobile when the replacement has none recorded.

Swap Mobile

Swapping . Pick another Assigned or In Store mobile. Holders and assignment details are exchanged. If either phone has a SIM, you must choose whether to Move SIM with holder or Keep SIM in this phone.

Assigned or In Store mobiles of the selected type (not this phone).
Accessories handed over with this swap. Pre-filled from the selected mobile, or from this phone when the other has none recorded. Saved on the mobile the original holder receives.
